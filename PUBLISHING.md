# Публикация только GLASS VEIL

Основной In Silico BBB и веб-сайт публикуются отдельно.
Для сайта создайте новый репозиторий GitHub и загрузите только подготовленный
комплект `.source/`. Не загружайте корень основного проекта и его историю Git.

## Подготовка

Из папки сайта `apps/atlas` в основной рабочей копии:

```powershell
npm ci --ignore-scripts --workspaces=false
npm run format:check
npm run build
npm run export:source
```

Получатся два каталога:

- `.pages/` — готовый сайт: проверенные HTML, CSS, JavaScript, изображения,
  структуры, шрифты, лицензии и `.nojekyll`.
- `.source/` — самостоятельные исходники сайта с npm-инструментами и
  `.github/workflows/pages.yml`. Содержимое этого каталога переносится
  в корень нового репозитория, включая файлы и папки с точкой в имени.

Экспорт использует явный список файлов. `bbb/`, API, модели, научная документация,
остальные приложения, `.git/`, локальные эскизы, `branding/` и
`design-baselines/` в комплект не входят. Предрассчитанный каталог восьми молекул
и готовые SVG логотипа включены: они нужны работающему сайту.
Папки `.source/` и `.pages/` исключены из Git основной рабочей копии.

## Отдельный репозиторий GitHub

1. Создайте пустой репозиторий для GLASS VEIL.
2. Перенесите в него только содержимое `.source/`, затем создайте коммит.
3. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
4. Отправьте коммит в `main` или запустите **Deploy GLASS VEIL** во вкладке Actions.
5. После успешного deploy откройте адрес environment `github-pages`.

Адрес: `https://<owner>.github.io/<website-repository>/`.
Сайт находится в корне своего Pages, добавлять `atlas/` не нужно.
[Официальная инструкция GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

Workflow устанавливает только инструменты сайта, проверяет файлы и публикует
только `.pages/`. Python, RDKit, MkDocs, API и база данных для этого не нужны.
На pull request выполняется проверка без публикации.

В отдельном репозитории команды выполняются из его корня:

```powershell
npm ci --ignore-scripts --workspaces=false
npm run format:check
npm run build
node serve.mjs --root .pages --base /glass-veil/ --port 4179
```

Локальный адрес для проверки вложенных путей:
`http://127.0.0.1:4179/glass-veil/`.
Все ресурсы и шрифты локальные, пути относительные.

## Граница публикации

Workflow в основной рабочей копии также изменён: он публикует исключительно
`apps/atlas/.pages/`, без MkDocs и других каталогов.
Однако публикация полного основного репозитория открывает его отслеживаемые
исходники независимо от состава Pages. `.gitignore` не скрывает уже отслеживаемые
файлы и коммиты. Для размещения только сайта используйте отдельный репозиторий
из экспортированного комплекта.

## Источники и лицензии

MIT относится к коду и собственным схемам; лицензия ParaType SIL OFL 1.1 включена
рядом со шрифтами. Сведения об изображениях: [dist/NOTICE.txt](dist/NOTICE.txt).
Разрешение на исходный аниме-кадр портретного контура в проекте не документировано;
этот файл не объявляется свободным по MIT.
Исходные страницы манги, музыка и временные кадры в комплект не входят.

Подготовка и экспорт выполняются локально: они не создают репозиторий,
не загружают исходники и не меняют видимость основного проекта.
